Argo CD is the GitOps continuous-delivery engine and the cluster bootstrap:
installed imperatively (../install.sh), it then manages everything else
declaratively from this git repo.

To bump: pull the new version, then VERIFY PROVENANCE before trusting it —
confirm the pulled tarball's hash matches upstream's published digest for
that version:
  shasum -a 256 <tgz>
  curl -s https://argoproj.github.io/argo-helm/index.yaml \
    | awk '/^  [a-z0-9-]+:$/{c=($0=="  argo-cd:")} c&&/digest:/{d=$2} c&&/version: <NEWVER>$/{print d; exit}'
The two must match. Then regenerate the .sha256, update CHART_VERSION in
../install.sh, delete the old tgz + sha256, update this file. Review the
chart changelog for breaking changes first (Argo CD majors can change CRDs).
